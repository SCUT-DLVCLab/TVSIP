## 📝 File Description

### OCR-based_Box_Rectification.py

Use OCR to enhance the bounding boxes from the MLLM and convert them to binary masks.

### locator_fusion.py

Fuse the results from both branches.

### mask_highlight.py

Highlight the final results on the image to be detected and provide a reference image for the Interpreter.

### mask_generation.py

Convert the MLLM results to masks without using OCR enhancement
